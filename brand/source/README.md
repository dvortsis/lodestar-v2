# Lodestar final asset exports

Tagline: **Every node is a new discovery.**

- `brand/`: approved brand identity sheet and mascot master.
- `logos/`: light/dark horizontal, stacked, and wordmark transparent exports.
- `icons/`: companion network compass symbols and mascot icons.
- `favicons/`: web and mobile icon exports and manifest.
- `tokens/`: Riverstone theme colors.
- `visuals/`: latest high-resolution light and dark individual scenes. See `manifest.json` for state-to-file mapping. Identical illustrated states are not duplicated.

**Limitations:** Standalone state illustrations are opaque PNGs, not transparent vector graphics. Several state names intentionally map to the same existing illustration. This export excludes legacy thumbnail previews, source comparison boards, earlier exploratory illustrations, and logo preview mockups.
