# X-web-polish-1101e: three small web follow-ups

Runner decision (§2.26): cost-limited versions.

- **#317 Illustrations on a first visit.** With no `lodestar.appearance` cache, `StateScene` shows no scene. The app writes the cache once the preference loads, so the next view has it. Accepted trade: a first-visit user with illustrations on sees no scene once; one with them off never sees one. A cache present, or Save-Data, behaves as before.
- **#322 Discover `j`/`k`.** Not fixed: cost. A toast was +0.45 KB on Discover for an offline edge case, and a retry costs more than the +0.05 KB allowed.
- **#254 Bulk manual copy.** The textarea closes when the selection changes, so it never holds stale magnets. Closing beats refreshing: the text is fetched asynchronously and a keyboard user would not know it changed. Focus moves to Copy if it was inside the box.
