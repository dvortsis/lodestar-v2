# X-web-polish-1101e: three small web follow-ups

- **#317 Illustrations on a first visit.** With no `lodestar.appearance` cache, `StateScene` renders nothing until the appearance boot sets `data-illustrations` on the root, then shows the scene only if it is `true`. A cache present, or Save-Data, behaves as before. If the preference never loads, no scene shows.
- **#322 Discover `j`/`k`.** A rejected `$lib/keys` / `./commands` import shows the existing error toast with the existing `discover_error_load` message (no new strings). No retry; the toast is enough.
- **#254 Bulk manual copy.** The textarea closes when the selection changes, so it never holds stale magnets. Closing beats refreshing: the text is fetched asynchronously and a keyboard user would not know it changed. Focus moves to Copy if it was inside the box.
