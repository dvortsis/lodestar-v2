## Finding: the Search results chunk fails silently
With the results chunk (`results-announce`) blocked on `/search?q=lantern`, the page shows only the query bar, with no results and no message, and raises an uncaught `TypeError: Failed to fetch dynamically imported module`. `loadResults()` in `web/src/routes/search/+page.svelte` has no `.catch`. Insights and Settings do show a retry state and are covered. This slice changes no app code and has no check for Search; a follow-up slice should add a retry state, then the check.
