# S-settings-2 decisions

**Scope: Language & region only (runner, 2026-10-31).** The other four screens (Integrations, Notifications, Trackers, Insights & digest) need server work that does not exist yet, so they move to S-settings-2b after a backend slice. The server needs:
- **Settings sections plus CRUD** for `integrations` (download clients, Torznab/*arr), notification channels with event routing, `trackers` (list, scrape on/off, cadence, health) and `insights` (digest schedule and channels, query logging, retention). Secrets use `writeOnly` fields as the form engine expects.
- **`POST /settings/test` kinds** for Torznab and each notification channel (ntfy, Discord, email, webhook). Today it accepts only `download_client`.
- **A clear-usage-data endpoint** for the destructive "Clear usage data" action (§10.10.7).
`GET /digest/preview` already exists; its preview mount point waits for S-insights-3.

**Language & region is a hand-built body over the shell's section form.** It shows only the `region` group of `preferences` (`language`, `time_zone`, `first_day_of_week`), so it does not repeat Appearance or Keyboard. The body is small and loads `shell/SectionForm.svelte` on demand, so saving, conflicts, the leave guard and env locks all come from the engine.

**Messages.** The `settings_preferences_*` label, help and option keys and `settings_group_region` are in the settings feature's `messages/{en,zh}.json`, so the generated `form/message-map.ts` picks them up. `message-map.gen.ts` now breaks an entry that would pass the 100-column print width after the colon, as prettier does; without it the generated file failed `prettier --check` and its up-to-date test once a long key existed.

**Size gating.** `.size-limit.mjs` treats the shell's section form as already gated by "Settings section" when a hand-built body loads it on demand: the body's first view and the extras entry stop at it. No limit was raised or added. Measured: Settings section 41.49 → 42.49 kB (45 kB cap; the generated map adds the preference labels), Language screen first view 21.32 kB, screen extras unchanged at 4.83 kB.
