# X-followups-1105 decisions (this PR)

Review follow-ups from SRC-17a (#462). No owner decision changes.

- **The plugin-name cache is single-flight with a 5 s back-off.** One slot per pipeline holds a `OnceCell` for the names and a `tokio::sync::Mutex` held across the listing, so concurrent first requests wait for one `sources()` call (which takes the store's writer lock) instead of each making their own. A failed listing is kept for 5 s; requests in that window get the empty map (every source by id, private: a public caller sees none, as before). Why: a pipeline whose `sources()` keeps failing would otherwise take the writer lock once per search. 5 s is short enough that a transient failure costs one stale page, not a stale session.
- **A search with no viewer does no provenance work.** Discover Newest (`search_get`, no viewer) neither lists the plugins nor reads the source catalogue; its output is unchanged (`discover_newest.txt` golden). Why: it threw both away.
- **The `pack_override` filter-note kind is not in this PR.** It needs RP-2 (#465), which hadn't merged when this slice ran; it goes in a follow-up once it has.
