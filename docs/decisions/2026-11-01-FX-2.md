# FX-2: Search narrow and touch (M5 design review B1, B5, I7, P6, P9, P10)

- **B1:** `Popover.svelte` gets `collisionPadding` 16 and, in `overlays.css`, `max-inline-size: 100vw − 2 × 16 px`; below 480 px the panel fills that width. Table and Live popovers inherit it. The rule is scoped to a `.ls-popover` class so Tooltip and Menu are unaffected. Test: the Syntax popover at 320 and 390 px stays inside the viewport with no sideways scroll.
- **B5:** one global `@media (pointer: coarse)` rule in `app.css` for buttons, `[role=button]`, `[role=tab]`, `summary`, `a.btn`, `nav a`, plus a `.target` class (table sort buttons, "Reset columns"). Removed the `.fr-preset` / `.fr-icon-button` copies in `facets.css`. Kept: `.fr-value` (a row, not a button), `.assist-option` (listbox option), `.rp-pick` and `.rt-check input` (checkboxes, I7). Copies outside FX-2's files are left for their owners. Test: touch-emulated sort button and "Reset columns" sizes in `search-table.routes.test.ts`.
- **I7:** row and table checkboxes use daisyUI `checkbox checkbox-sm`, the field border and `FOCUS_RING`; the coarse rule is kept. Deviation: native inputs, not the `Checkbox` primitive, because it wraps a visible label and these cells carry their own `aria-label`.
- **P6:** the open top bin's tick reads "<last edge> +" through a new `tickLabels` prop on `Histogram`; tooltips and slider text keep the plain edges. Edge thinning is unchanged (the longer label can thin ticks further).
- **P9:** a CSS sibling rule (`assist.css`) hides the Field / Operator / Value captions visually on every Builder row after the first rendered one; they stay as screen-reader text, so accessible names are unchanged. Done in CSS because a prop and per-row logic pushed the Builder chunk over its size limit.
- **P10:** the query bar is capped at `max-w-6xl` from `xx-large`, left-aligned with the page. Deviation: the results column is fluid, so this is a Tailwind step near its width, not its exact width. The 1920 and 2560 Search baselines change on purpose (marker file added).
