# FX-2: Search narrow and touch (M5 design review B1, B5, I7, P6, P9, P10)

- **B1:** `Popover.svelte` gets `collisionPadding` 16 and, in `overlays.css`, `max-inline-size: 100vw − 2 × 16 px`; below 480 px the panel fills that width. Table and Live popovers inherit it. Test: the Syntax popover at 320 and 390 px stays inside the viewport with no sideways scroll.
- **B5:** one global `@media (pointer: coarse)` rule in `app.css` for buttons, `[role=button]`, `[role=tab]`, `summary`, `a.btn`, `nav a`, plus a `.target` class (table sort buttons, "Reset columns"). Removed the `.fr-preset` / `.fr-icon-button` copies in `facets.css`. Kept: `.fr-value` (a row, not a button), `.assist-option` (listbox option), `.rp-pick` and `.rt-check input` (checkboxes, I7). Copies outside FX-2's files are left for their owners. Test: touch-emulated target sizes in `smoke.test.ts`.
- **I7:** row and table checkboxes use daisyUI `checkbox checkbox-sm` with the field border; the coarse rule is kept. Deviation: native inputs given the class, not the `Checkbox` primitive, because the primitive wraps a label and these cells carry their own `aria-label`.
- **P6:** the open top bin's edge reads "<last edge> +" (RangeGroup). The edge-fitting logic already labels every edge that fits.
- **P9:** the Field / Operator / Value captions show on the first Builder row only; later rows keep them as `sr-only` text, so accessible names are unchanged.
- **P10:** the query bar is capped at `max-w-6xl` and centred from `xx-large`. Deviation: a Tailwind step near the results column, not its exact width.
