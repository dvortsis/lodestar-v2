# S-updates-2 decisions (Settings → Updates, part 2)

Continues `2026-11-01-S-updates.md`. No owner decision changes; these are runner-level refinements (`docs/owner-decisions.md` §2.19).

- **Advanced is built (`Advanced.svelte`, loaded when the section is first opened).** It follows part 1's store pattern, not `form/embed.ts`: the screen already holds the `updates` section's values and revision, and the engine would have added a second consumer's graph to this screen. Channel (radios), days to wait (0–14), install window (`HH:MM-HH:MM`), allow index rebuilds, and the three notify toggles are saved one at a time with `if_revision`. A refused or failed save puts every control back on the server's value and shows the server's words; locked (environment or read-only) fields are disabled with the variable named.
- **Channel dialog.** Choosing another channel asks first through the existing dialog; Cancel and Esc send nothing. The text is from §12.2: Beta and Nightly say they are tested less or for testing only and that the change may need a restore from a snapshot; Stable says Lodestar never goes back to an older version and waits for the next Stable release. It says the change applies to the next check.
- **Notify toggles say they are stored only** ("Messages are sent once notification channels are set up"), as the settings code documents.
