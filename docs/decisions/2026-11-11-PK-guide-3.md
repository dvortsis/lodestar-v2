# PK-guide-3 decisions

User guide for Windows updates, rollback and Restart now (`docs/user/04-install-on-windows-and-linux.md` §4.8, Appendix B). Where the brief and the code on `origin/main` (f05fe580) disagreed, the guide follows the code. Calls marked "runner" are the runner's to confirm.

- **Windows never installs by itself, so the install window doesn't apply.** `update/windows/check.rs` (module docs, lines 18-24; `incapable()`) treats Install automatically as Check and notify, and `policy::install_now` (`update/policy.rs:271`) ignores the window and the wait. The guide says the window holds back automatic installs only and that **Install now** skips it. The brief's "what happens outside the window" has no Windows behaviour to describe.
- **Install now isn't withdrawn while updates are Off or paused.** `policy::install_now` has no mode or pause check, and `check.rs` `install_now_while_off_still_installs` pins it. What Off or a pause does is take back an Install now that is still waiting for the helper (`docs/decisions/2026-11-11-X-win-upd-window.md`). The guide says that, and gives the real reasons the button is missing (`cannot_install`, `check.rs:904`; `portable::cannot_install`, `portable.rs:238`).
- **The web page has no Restart now button yet.** `web/src` never calls `restartSystem`; `SectionForm.svelte` shows only "N changes apply after a restart." The server side is built (`POST /system/restart`, `GET /system` estimate and hint). The guide marks the button **(planned)**, points to `Restart-Service` and Ctrl+C meanwhile, and describes the built behaviour: the service's pause of about a day (`windows/service.rs:351`, including the first start after an upgrade, `docs/decisions/2026-11-08-PK-win-restart.md`), the estimate of the last start plus 60 s, SCM events 7024 and 7031, and the portable relaunch. Runner: tell me if a Restart now button is due before G-m6, and the guide changes in a line.
- **Manual Roll back isn't available on Windows** (`check.rs` reports `rollback.available=false`, `not_built_yet`). The guide says automatic rollback only, and to install the older MSI by hand.
- **Event Log facts.** Service, source `Lodestar`, WARNING, ID 4 while a rollback holds the store (`windows/service.rs:151`, `event_log_text`). Helper, source `Lodestar update helper`, ERROR, ID 900, when it refuses or can't finish an install (`update/windows/helper.rs:1476`). The guide says "Error, event ID 900" for a failed rollback; the helper writes it when a rollback halts (`helper.rs:803`).
- **Numbers.** Health hold 60 s within 5 min (`helper.rs:91-93`); portable probation 5 min and 3 attempts (`portable.rs:84-87`); default window `03:00-05:00`, wait 3 days (`config.rs:460`).
- **Layout.** The new section is 4.8; Check your understanding moves to 4.9 and gets a fifth question (Appendix A). Troubleshooting rows are in the section, so `06-troubleshooting.md` is untouched.
- **Figure.** `windows-update-status-illustration.svg` is an illustration of the status card, listed in `SHOTLIST.md`.
