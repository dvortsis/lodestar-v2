# X-detail-attributes-ui decisions

- **The Release list sits in the Parsed section, not under Technical details** (runner, step 0, §2.26). §10.5 item 3 is where parsed metadata lives, and an expert-only disclosure would hide it from the people it helps. This refines the brief's default.
- **A "Release" `<dl>` under Parsed's rows**, from `TorrentDetail.attributes`. Null and `{}` show nothing. A key without a label is dropped, never shown raw.
- **Overlap with the title identity rows.** Parsed already shows year, season, episode and absolute from the siblings answer (the title's spans across versions). The list leaves a key out when its row is shown, and shows this torrent's own value (Year, Season, Episode, Absolute episode) when it isn't. `title` shows only when it differs from the resolved title.
- **One label set with Compare** (review finding; the #1172 decision says one torrent reads the same in the detail view and Compare). Key labels are Compare's `compare_attr_*` messages and values go through `format/label-release` `attributeLabel` (codecs as "H.265 (HEVC)", `source`, `hdr`, `lang` and `subs` in the UI language, `multi` as "Multiple languages", `group` as sent). This replaces the labels the runner approved at step 0 (Audio languages, File format, Release tags, Streaming service, Also known as, Absolute episode); Compare's words won, so the two views agree. Only `sample`, `version`, `platform` and `arch`, which Compare has no label for, have `detail_attr_*` messages.
- **Formatters the shared module doesn't have, kept in `parsed/release.ts`** (`format/label-release.ts` is outside this slice's `owns`): `bits` as "10-bit", `pack: yes` as "Season or collection pack", and all 16 `service` names (about 140 B gzip). Moving them into `label-release.ts`, so Compare shows them too, is a follow-up.
- **Order is Compare's** (`ATTRIBUTE_ORDER`), with `sample`, `version`, `platform` and `arch` before `flags`. Year, season, episode and absolute are held back while the identity rows load, so nothing appears and then vanishes.
- **zh strings are machine-drafted** and need a human pass.
- **Glossary:** `release_list`, `pack`, `release_group`, `container_format` (Container) and `release_tags` (Flags), worded as Compare words them.
- **Size** (measured, rounded up to 64 B; main passes all three at its own limits): Detail sections 47.52 KB → 50,560 B (measured 50,514 B, +3.0 kB: Compare's shared label tables and messages come with the shared wording; the version with its own labels cost +1.48 kB and read differently), Detail drawer 28.27 KB → 28,352 B (28,301 B), /t/[hash] 15.71 KB → 15,744 B (15,718 B).
