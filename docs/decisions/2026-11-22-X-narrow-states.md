# X-narrow-states decisions

Track U, from the UI review of 2026-11-13 (findings I7, I17, I28 for Logs, P9, P12, P13 and the About copy of P10). The runner's calls are in its message of 2026-11-22Z (§2.26, r14). Each is flagged to the owner, who can veto it (§2.19).

- **Discover hides every section the server can't build yet (I7, §10.7).** A Rising or Recently resolved section whose group is `unavailable` with a `needs_*` reason isn't rendered, so there is no "Not available" shell and no "coming soon". When both are hidden, Newest takes the full width. Other reasons (`no_title`, `search_disabled` for a section) keep their short notice. The page-level `search_disabled` empty state is unchanged. `unavailable.ts` stays whole: Discover is its only importer, but it must stay exhaustive on the generated union, and the filter lives in the page.
- **Logs on a phone (I17).**
  - **Below 640 px a row is two lines:** time, level and component, then the whole message, wrapped. From 640 px it is one line with the message cut short, as before.
  - **The default is decided in CSS,** not by `matchMedia` after mount, so the list doesn't move after the first paint. The Wrap toggle starts unset: the CSS decides until the user presses it, then their choice wins (`logs-wrap`, `logs-one`). The toggle's pressed state follows the screen width until then.
  - **The list's row estimate is 44 px on a narrow screen** (28 px otherwise), the measured height of a two-line row, so measuring rows moves nothing. `narrow-states.routes.test.ts` checks that the log list has no layout shift at 390 px (bound 0), counted after the fonts are cached.
  - **Component filters** show a check icon when on and a bordered button when off, so the state is never colour alone. The icon is `ph/check-circle-bold`, which other screens already load: the new `ph/check-bold` re-split a shared chunk and put Detail sections 205 B over its limit.
- **Logs labels (I28).** The level select and the filter box have visible labels above them (the existing `logs_level_label` and `logs_filter_label`). The zone part of I28 was done in #1023.
- **Filled empty states (P9, my screens only).** Logs' empty state says why it may be empty and links to Settings → Logging (`logs_empty_text` changed, `logs_empty_action` added). Discover's empty states already had a sentence and an action. The Alert detail and table view blank cards, and the wizard's 12-step list, are not in this slice's paths: the runner queues them as follow-ups.
- **Narrow layouts (P12).**
  - **Discover's type tabs** get a trailing fade that's gone once the strip is scrolled to its end (a scroll-driven animation on a registered length, tokens only), plus an sr-only line, `discover_tabs_more`. Browsers without scroll-driven animations just scroll with no fade. There are no arrow buttons.
  - **Logging's Verbosity** is a one-per-row list below 640 px, not five segments wrapping unevenly (CSS only: the same control, `display: grid`). Approved by the runner for this one change (`settings/logging/**`, its own commit). A select was tried and dropped: through the shared `Select` it put Settings logging parts 115 B over its limit, and a bare `<select>` re-split shared chunks (a dozen entries over). The filter rail stays with its owner.
- **About (P13, P10).**
  - **External links** carry the external-link icon as well as the sr-only "opens in a new tab" note. The icon is a small inline SVG (`ExternalIcon.svelte`, Phosphor's arrow-square-out path): importing it from the icon set re-split a shared chunk and put Compare 135 B over its limit.
  - **Times** that were relative with the absolute time only in a `title` (and an sr-only copy) now show the date as text beside the relative time, so a phone sees it. The only absolute time that sat in a `title` alone was in `RelativeTime`; the About screen no longer relies on it.
  - **The tagline** prints once. The horizontal lockup already carries "Every node is a new discovery" in its artwork, so the text copy is sr-only.
  - **"Interface build"** is hidden when its value is the `0.0.0` placeholder or only repeats the server's version or commit (`showUiBuild`).
- **Size.** No `.size-limit.mjs` change. Final entries on this branch: Logs route 37.25 / 39.6 kB, Discover route 42.13 / 43 kB, Settings AboutScreen first view 34.12 / 45 kB, Settings about parts 3.18 / 3.44 kB, Settings logging parts 17.54 / 17.55 kB (tight: the next change there should pay with a removal), CSS 19.79 / 19.80 kB. My new CSS is scoped in the components; no new Tailwind utility class was added, because the global sheet has 10 B of headroom.
