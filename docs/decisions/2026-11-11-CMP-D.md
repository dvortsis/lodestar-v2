# CMP-D decisions

The user guide chapter on companions (`docs/user/08-add-companions.md`). Spec: architecture §18.10 and `docs/owner-decisions.md` §2.14. None loosens an owner decision or weakens a security decision.

- **The chapter is `08-add-companions.md`, not `07-…`.** The brief allowed a numbered file starting `07-`, but Chapter 7 (`07-connect-other-apps.md`) already exists, so the next free number is used. The README task finder, Appendix A, the glossary (companion, download client) and revisions (3.1) gain additive entries.
- **Everything is marked "(newer than v0.5.1)"** as `docs/operations.md` does, with one callout at the top of 8.1.
- **The guide says plainly that the shipped catalogue has no pinned download yet.** Every `pin` and `digest` in `crates/companions/data/catalogue.json` on `main` is `null` (CMP-0's "awaiting pin" state), so the app answers "This companion isn't available to install yet." The guide sends readers to the container and detected-companion paths meanwhile. It names no version or checksum.
- **The guide marks the "managed containers" socket-proxy mode as (planned).** Nothing in `crates/` builds it; §18.10 describes it as advanced and off by default.
- **Windows qBittorrent is documented as a guided install,** following `crates/companions/src/windows_qbittorrent.rs`: Lodestar never downloads or runs the installer. The UI shows no step list for it today, so the guide gives the steps.
- **Screenshot:** CMP-9a's e2e takes none for the docs, so Figure 8.2 is an SVG illustration, with a SHOTLIST entry for a fixture capture.
- **Facts checked against `main`:** `crates/lodestar/src/cli/companion.rs` (commands, options, refusals); `crates/companions/src/compose.rs` and `unraid.rs` (what is and isn't written, templates-user path); `detect/mod.rs` (where it looks); `configure/qbittorrent.rs` and `configure/prowlarr.rs` (what is set); `supervise/mod.rs` `Timings::default` (30 s health, 3 failures, 1 s to 5 min backoff, 5 crashes in 10 min); `web/src/lib/features/settings/companions/messages/en.json`, `wizard/messages/en.json` and `companions/messages/en.json` (every UI label).
