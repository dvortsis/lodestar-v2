## Fixture project

`playwright.config.ts` gains a `fixture` project matching `*.fixture.test.ts`. Like `all-themes` it exists only when asked for (`--project=fixture` or `E2E_FIXTURE=1`), so default, `core` and matrix runs never see it. The specs also skip unless `E2E_FIXTURE_URL` is set. `web/e2e/README.md` documents the local run.

## Follow-up: a fixture CI job

Not added here. It needs the Rust binary in the e2e workflow: `cargo build -p lodestar --release` is roughly 6–10 min on a cold runner cache (about 1–2 min warm with the shared rust-cache), plus fixture generation and server start, on top of the existing ~75 s web build. It would run on one runner, in the existing Playwright container (which needs a Rust toolchain added or the binary built in an earlier job and passed as an artifact, the cheaper route). A nightly schedule avoids adding that cost to every PR.
