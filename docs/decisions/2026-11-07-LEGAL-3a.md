# LEGAL-3a decisions

**A facts test keeps the Legal Notice tied to the code (runner brief; spec `2026-11-06-X-legal-docs-r2.md`, "LEGAL-3").**

- **Test location and method.** `crates/lodestar/tests/legal_facts.rs`. `lodestar` is a binary crate, so integration tests can't import its modules. Facts in library crates (peer TTL, secret store, notify channels, source manifests, the store's private flag) use the real values; facts in the binary's own files (`services.rs`, `config.rs`, `settings/logging.rs`, `windows/temp_log.rs`, `cli/backup.rs`) are matched in the source text, on every platform, so no `#[cfg(windows)]` is needed.
- **Exports, no behaviour change.** `lodestar_dht::PEER_TTL` is now defined in `crates/dht/src/lib.rs`; the peer table's `TTL` is that value (`node/mod.rs` keeps `peers` private, so this avoids touching it). `cli/backup.rs` gains `BACKUP_FILES`, which the backup now takes its file names from.
- **The notice is never edited by the test or this slice.** Every claim held against the code when the test was written. A failure names the section; a person decides whether the notice version rises (§2.33).
- **Event Log.** The test asserts the notice doesn't name the Windows Event Log, as no code writes to it.
