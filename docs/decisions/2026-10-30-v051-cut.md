## Delta from the soaked build
The change classes are those of master plan Part D2: A is crawler lifecycle, sampler or endpoint policy; B is store, search, filters, metainfo, API or updater; C changes nothing that ships.

### Class A: needs a soak on the cutoff artifact
- **CR-0f (#200):**
  - the seed exemption is narrowed;
  - NAT64 seeds are accepted as 64:ff9b::/96 or 64:ff9b:1::/96 with a public embedded IPv4, and other local-use prefix lengths are refused;
  - on resume, the DHT resumes before the pool, and the pool still pauses first;
  - `lookups_completed` counts cancelled requests per its amended contract.

  Soaked by the release gate's 24 h Unraid run on the rc image, plus the ≥ 2 h gluetun leg.
- **Earlier class-A items (A1, A2):** trivial, test code and log text only. No soak needed.
