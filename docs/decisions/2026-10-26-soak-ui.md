# Soak UI follow-up decisions (local slice)

- **Inline detail must fit its composition (§10.5/§10.15).** The wide breakpoint permits inline placement only when measured container width fits the rail, results minimum, gaps/padding and clamped persisted drawer width. Otherwise detail remains overlaid. Resizing recomputes placement; desktop remains non-modal.
- **Fullscreen detail covers background interaction.** While open below 640 px, ancestor sibling branches become inert. Cleanup restores only previously non-inert branches on close, route exit or resize. Focus moves into detail if it becomes fullscreen while focus is outside. Existing popup portals opened from detail remain available. An empty, persistently mounted host has no covering box.
- **Insights offsets follow rendered height.** The context bar reports its actual height, including wrapped controls and custom dates. Scroll margin belongs to the focused target heading, not only its parent section.
- **Narrow rows prioritize size and availability.** Container queries hide secondary facts, raw names and the copy-action text; accessible button names remain. They do not change the selected density. Composition headings follow their page/drawer parent level, Compare landmarks have distinct translated names, and complete short Discover lists shrink to loaded row height.
- **Unfinished destinations explain their availability.** Settings (including `/settings`) and Insights stage placeholders provide translated unavailable states and working return links. The shared overflow/palette list omits nonexistent Logs and Syntax routes. This does not implement deferred Settings/stage features or change the existing Search syntax popover.
- **Rendered acceptance is deferred.** Source formatting, syntax compilation and lint are distinct from browser, type, accessibility and visual validation. The post-soak checklist covers these boundaries before publication.
