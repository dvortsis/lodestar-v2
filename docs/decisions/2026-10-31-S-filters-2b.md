# S-filters decisions, part 2b: the Adult facets; "Block this…" moves to 2c

- **Adult facets name their subtypes in words.** The facet rail labels the `adult` facet's values (Scene, Movie, Photos, Comics, Game, VR, Audio) with the messages the query chips already use (`ADULT_VALUE`, now exported from `search/query/clauses.ts`). Before, they showed the raw server values.
- **Whether Adult facets show is the server's call** (§20.9, B17): with "Show adult content" off, the server leaves adult out of facet counts and lists no `adult` facet or `type=adult` value, so the rail has nothing to show. The rail adds no second check. A client-side check would need its own `GET /settings/content` read in Search, and the Facet rail has about 0.1 KB of headroom. Tests show that the rail renders nothing adult when the server lists none. The 18+ confirmation is the existing flow (`createAdultConfirm`, Settings → Appearance).
- **"Block this…" in a result's menu and the detail drawer moves to part 2c** (runner, §2.26, option B). Measured with the dialog loaded lazily through a one-hop forwarder and one menu item or button, one state and one import in `RowActions.svelte` and `DetailActions.svelte`:

  | Entry                         | `main`   | With the hooks   | Limit   |
  | ----------------------------- | -------- | ---------------- | ------- |
  | Search results (lazy)         | 43.28 KB | 43.58 KB (+0.30) | 43.3 KB |
  | Detail drawer                 | 28.87 KB | 29.19 KB (+0.32) | 29 KB   |
  | /t/[hash] route               | 22.51 KB | 22.82 KB (+0.31) | 22.6 KB |
  | Settings → Filters first view | 32.99 KB | 59.48 KB         | 45 KB   |

  Once Search and the drawer can reach the flows' dialogs, the bundler regroups the shared flow and overlay code, and the Filters screen imports it statically (its first view grows by 26 KB, and "Filters dialogs (on demand)" falls from 30.4 to 9.2 KB). Reverting only the two hook files restores 32.99 KB. 2c waits for X-alert-search-headroom, which isolates `filters/flows` and `ui/overlays` into their own chunks. The `BlockThis` wrapper is not shipped in this part, so no dead code lands.

- **Sizes** (gzip, `main` → head): Facet rail (lazy) 16.60 → 16.70 KB (limit 16.8), Search results (lazy) 43.28 → 43.29 KB (limit 43.3), Alert route 45.98 → 45.98 KB, Alerts route 29.17 → 29.17 KB, Results toolbar 4.59 → 4.60 KB. No limit was raised and no size entry was touched.
