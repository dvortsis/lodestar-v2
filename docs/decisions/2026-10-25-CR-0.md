# CR-0 decisions (local implementation, PR pending)

- **Sampler ownership (§5).** Reserve a bounded endpoint slot before dispatch. An indexed expiry set holds exactly one entry per cooling endpoint; reclaim at most 1,024 per maintenance turn. Keep the 200,000-state and 20,000-frontier bounds. Missing/invalid/error/timeout responses impose six hours of backoff; valid intervals retain the 60-second floor. No unexpired obligation is evicted for capacity.
- **Restart safety (§5).** Suppress sampling for six hours plus the configured query timeout after every production start. Routing, passive service and peer lookup continue. `sample_start_delay: Some(...)` is an explicit isolated/fresh-history library override, absent from application wiring. This knowingly delays post-restart yield; it avoids introducing a durability protocol in CR-0. Measure the baseline after suppression and report the delay separately.
- **Wire correlation (§5).** Eight-byte tokens start at a random session value and never wrap within a process. Exhaustion defers new queries; replies still work. Endpoint/family/expected-node checks remain. Session randomness does not guarantee rejection of every packet delayed across a restart. Missing and empty BEP 51 sample fields remain distinct and borrowed.
- **Public endpoint policy (§§5–6).** The dependency-free internal `network-policy` crate gives DHT and peer wire one conservative outbound policy. Canonicalize mapped IPv4, reject zero ports and special/private/reserved destinations before retaining candidates and at dispatch, and preserve live subscribed-IP checks. IPv6 permits native global unicast, excluding special-purpose IETF, transition and documentation blocks. This deliberately excludes some globally reachable special-purpose addresses; it is not a general routing oracle. Local library fixtures explicitly opt in. Public inbound protocol replies are not subjected to this outbound restriction. Range references: [IANA IPv4](https://www.iana.org/assignments/iana-ipv4-special-registry/) and [IANA IPv6](https://www.iana.org/assignments/iana-ipv6-special-registry/).
- **Lookup ownership (§18.4).** A bounded source request carries a one-shot admission reply; acceptance returns a distinct terminal receiver. Only positive acknowledgement consumes an attempt. The pool polls its bounded receiver set, with no task per discovery. Receiver drop cancels queued or active work. The pool releases its reservation locally once; the actor independently cleans family legs/RPCs and maintains its own hard admission cap. Cancellation does not wait for a terminal message on an already dropped receiver. This replaces the earlier sketch requiring both receiver-drop cancellation and a subsequent caller acknowledgement.
- **Resource bounds (§§5,18.4).** At most 32 accepted logical peer requests across queued and active work; each owns all configured families, at most three simultaneous queries, 64 sent queries and 64 deduplicated terminal peers. Ordinary/maintenance lookup legs have a 25-second deadline; scrapes retain 30 seconds. Cancel/deadline cleanup removes pending address accounting. Scheduled continuations retry throttling/WouldBlock and advance permanent failures. Maintenance turns run ahead of packet floods, and continuations precede sampling; existing intensity/global caps and sample headroom remain. Later priority lanes are still CR-2.
- **No fictitious private attempts (§18.7).** Private keys without supplied peers remain in the bounded, evictable pool waiting for their source. They never go to public peer finders and no longer burn attempts for public work that was never dispatched. Likewise, temporarily unavailable/rejecting finders defer work without consuming attempts.
- **Diagnostics (§12.1).** A typed `dht.socket_buffers` event records requested/granted receive and send buffers plus set/readback error counts. Preserve the existing 4 MiB receive request and system-default send buffer (`send_requested=0`), without tuning either policy. A failed readback is unknown, represented by a zero placeholder with nonzero `read_errors`; no kernel-drop estimate is invented. Aggregate sampler/admission/cancellation/deadline gauges and counters have no endpoint or hash labels.

No schema change, external dependency, target-prefix experiment, streaming, uTP wiring, deployment change or throughput claim is part of this slice. The [implementation plan](../plan/dht-crawler-implementation-plan-2026-10-25.md) retains those later gates.
