# X-detail-polish decisions

Runner brief, 2026-11-01. Follow-ups from S-filters-2c (#316) and S-send (#321). No owner decision changes; Block still only adds a rule, and Cancel or a refusal still sends nothing.

- **Done: a hidden torrent drops after Block (item 1).** After a successful apply, the drawer's and the result menu's "Block this…" fire a `ls-stale` event on `window`; a one-time listener in `RowActions.svelte` (loaded with the first results) calls `results.reload()`. An event rather than an import, because any import of the results store from the drawer pulled it into the drawer's size entries (+1 KB). With no list (`/t`) `reload` makes no request. Cancel and refusal never call `onapplied`.
- **Done: a failed flows door shows the error toast (item 2).** The drawer's `load()` failure (the door import and `load()` itself) now pushes the same error toast as magnet copy/open, through `commands.ts` on demand, so the toast store stays out of the first view.
- **Done: the Send label follows Settings (item 3).** The drawer asks `sendLabel(true)` when it mounts, which re-reads the integrations section instead of using the session cache. It runs after mount, never in first paint. No settings-saved event exists, so this is the "cheap re-check when the drawer opens" option; the result menu still reads on its first More.
- **Skipped: stale-press guard on Send (item 4).** The Send button is only shown after `send.ts` has loaded, and it calls `sendHash` synchronously, so no window exists between a press and the module loading. The row menu's hash is the row's own. Adding an async hop just to guard it costs ~+60 B in the drawer and /t entries, which have <30 B left of the +0.1 KB budget.
- **Skipped: `s` waits for the torrent on /t (item 5).** It needs the drawer to publish "loaded" state to `send.ts` (an effect plus a target export), ~+50 B in both entries, over budget with items 1–3. Suggested alternative for later: `DetailHostBody`/the /t page set the key target only once `model.detail` is present.

Sizes (gzip, before → after): drawer 27,186 → 27,265 (+79), /t 20,828 → 20,907 (+79), Search results 43,115 → 43,193 (+78). Alert, Alerts, Results toolbar, Discover and CSS unchanged.
