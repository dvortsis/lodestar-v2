# CR-COL-4 decisions

Runner, 2026-11-03. Build-plan §0.2 and §0.4; `docs/decisions/2026-11-03-soak-r3-verdict.md`.

- **The memory bar is unchanged.** `MEMORY_FIT` stays an upper 95% CI ≤ 2.0 MiB/h over baseline hours 12-24. This slice only labels and adds context.
- **The collector keeps two more series.** `lodestar_search_commits_total` and `lodestar_search_mmap_cache_entries{index}` join the snapshot allowlist (`STORAGE`), so r4 can show private memory against commits. The existing label check already accepts `{index="main"}` and `{index="files"}`. Older binaries lack the gauge, so neither series is required.
- **The analyzer reads them from snapshots only.** It reports private MiB per 1,000 search commits beside the per-1,000-torrents slope (informational, never gated), and the gauge's first, last and max per index. Evidence without the series analyzes as before, with the new fields absent.
- **An incomplete window gives a provisional fit.** r3's early fit (hours 12-16) read 6.66 MiB/h and the full window 1.88. A fit over a window the analyzer judges incomplete now prints `provisional (window incomplete)`, with no pass or fail wording, and carries `provisional: true`. A complete window is unchanged: no new key, same wording.
- **r4 pins its tooling.** The soak record names the collector and analyzer git revision next to the rc.3 image digest.
- **Docs fix:** build-plan §0.9 now says X-strip-format-chars merged as #373.
