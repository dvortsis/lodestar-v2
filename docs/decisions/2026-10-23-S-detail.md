# S-detail decisions

The detail drawer (`DetailHost`), `/t/{hash}`, the file tree with its worker, composition, parsed metadata and the raw viewer (§10.5). Runner and owner decisions this slice applies are in its brief; what follows is what the slice chose where the brief left it open.

- **The page column (`/t/{hash}`):** a single column capped at `--manuscript-width` (720 px), with the title as the page's `<h1>`. It's prose-and-facts, like Settings, so it takes the same measure (§10.2). The drawer and the page share `DetailView`; only the container differs.
- **Drawer width storage:** `localStorage` key `lodestar.drawer.width`, a per-viewer convenience, wrapped in try/catch. A missing, blocked or invalid value falls back to the token width (`--drawer-overlay-width`, through the `Drawer` primitive's default). The stored width applies where the drawer is in flow (xx-large and up); the overlays use their tokens (560 px at x-large, 480 px at large) and full screen below large.
- **Directory order in the tree:** directories before files, each by a numeric-aware collator in the UI locale (`Intl.Collator(locale, { numeric: true })`, the same comparison as `localeCompare(…, { numeric: true })` but built once, so 50,000 paths sort in well under a second). Directory ids end in `/` and file ids never do, so a file and a folder with one name can't collide; a repeated path gets a numbered id.
- **Folder sizes:** the exact integer sum of the server's sizes of the files shown under the folder (padding hidden means padding left out), formatted once with `formatBytes`. It is a structural sum, as the primitive's `leaves` count is, and shows no percentage (§10.5, `docs/metrics.md` §3). A filter never changes a folder's size.
- **`executable` and `symlink`** show as words before the size (`executable · 4.00 MiB`), in the tree's size cell. `FlatNode` has no badge field and the brief allows one new field (`marked`), so the words travel in the formatted `size` string. A real badge column is a follow-up for the tree primitive.
- **The interim hash lookup:** `TorrentDetail` doesn't carry `title`, `resolved_via`, `content_type`, `adult_kind`, `composition`, `junk_score`, `junk_reasons` or `matched_files` yet (`docs/metrics.md` §7.1 "planned on detail"). From Search the cached hit supplies them; on a direct load the view asks `GET /search?q=hash:{hash}&limit=1&hidden=true` and takes the first hit only if its `hash` matches. When detail carries the fields this lookup goes away.
- **The fallback copy UX:** `copyText` uses `navigator.clipboard` in a secure context and a hidden-textarea `execCommand('copy')` otherwise or on a throw. A plain-HTTP LAN address (the usual Unraid setup) is not a secure context, so the textarea path is the normal one there. When both fail, a selected read-only field shows the magnet with "Press Ctrl+C to copy" (⌘C on a Mac).
- **Section lazy-loading:** Summary is in the first chunk. Contents (composition and the tree, with the virtual list) and Parsed are separate chunks, imported when their section first scrolls within 200 px, with `content-visibility: auto` on every section. The error states are a chunk too. `{#await}` isn't used: its runtime would be shipped with the search route (Svelte's runtime is one shared chunk). The tree's worker is a module worker from a same-origin file (`script-src 'self'`), never a `blob:` URL.
- **Detail messages:** keys are `detail_*`. Shared keys added to `lib/i18n/messages`: the group labels `images`, `documents`, `archives` (the other four groups reuse `video`, `audio`, `software`, `other`), `dominant_share` (`{share} {group}`), the content-type values `content_type_*` and the adult kinds `adult_kind_*`, all in the glossary's wording. zh proposals are included for them (the runner asked for both languages); the glossary still marks its zh labels TBD.
- **No `{@html}`, no other URL from torrent data.** Names and paths are rendered through Svelte's escaping. The magnet is the only URL taken from torrent data, and only after `isMagnet` (`^magnet:\?`).
- **Search shown as current at `/t/{hash}`:** `isActive` marks the Search destination for any `/t/…` path.
- **Provisional:** the adult-hidden state links to `/settings/appearance`, which S-appearance owns.
- **Scrape age shows both:** "Seen 3 hours ago" through `RelativeTime`, plus the absolute time (`formatDateTime`) as visible text, because §10.12 and `docs/metrics.md` §4 want the absolute time in the drawer.
- **The resize handle** is shown, and its width saved, only where the drawer is in flow; overlays and the full-screen view use fixed widths.
- **One line outside the brief's owned paths:** `web/e2e/routes.keyboard.test.ts` now calls `route.mock?.(mock)`, as `smoke.test.ts` does, because the `torrent` route needs its API mocked. `lib/shell/shell.test.ts` flips one assertion (`isActive(search, '/t/abc')`) to match the runner's one-line `nav.ts` change.
