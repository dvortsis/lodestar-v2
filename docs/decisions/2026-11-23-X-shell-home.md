# X-shell-home decisions

Slice session, 2026-11-23Z. Brief and rulings: the runner's brief of 2026-11-22Z and its go message (§2.26 UX calls, flagged to the owner under §2.19). Findings: P5, P6, U27, D11 and 02 §4d of the 2026-11-13 UI review. Spec: §10.3, §10.4.

- **Status pill words (U27).** crawling → "Working", idle → "Ready", stalled → "Needs attention", unknown and connecting → "Connecting…" (one word for both, so the first frame and the first snapshot read the same). "Needs attention" is the glossary's own term (`needs_attention`), so its wording wins. Paused, Reconnecting, Server busy, Rebuilding, Index rebuild failed, Starting and Restart needed are unchanged: they already say what is happening. The count stays ("Working · 2.2K torrents"). **No rate is added:** there is no trustworthy hourly figure, and the pill must not compute one. The fleet text keeps its slot after the count for WK-17. Announcements are unchanged: one polite region that speaks on a change of state, not on every poll.
- **Palette button (P5).** A keyboard device shows the keys it answers to, spelled as the shortcut sheet spells them (`formatCombo('mod+k')`: "⌘K" on Apple platforms, "Ctrl+K" elsewhere); a touch device (`pointer: coarse`) shows a magnifier, since there is no ⌘ there. Decided once at first render, so the bar never changes size. The accessible name is "Search and commands" plus the visible keys (WCAG 2.5.3 label in name), or just "Search and commands" on touch; the dialog's own title stays "Command palette".
- **Overflow menu (P5).** Items are unchanged: Import and Backup have no Settings screen yet, and the Syntax guide waits for `/help/syntax` (X-help). **Page shift:** opening the menu set `overflow: hidden` on `<body>` (Bits UI's scroll lock). Where the browser shows a classic scrollbar, the lock removed it and the page moved by its width. A dropdown menu is not modal, so `ui/overlays/Menu.svelte` now sets `preventScroll={false}` (runner, §2.26): this applies to every menu built on it (the row menu, the detail actions, the field menu and the overflow). No `app.css` change (the global CSS limit stays). The headless browser in CI has overlay scrollbars, so the e2e asserts the lock is gone rather than a pixel shift; Esc, an outside click and focus return still work.
- **Search home (P6, D11).** The empty state is its own component, `search/home/Home.svelte`, loaded in the same `Promise.all` as the results panel and passed to it, so it is in the first frame. It says what Lodestar is and what to type, shows a health sentence from the pill state, and lists recent searches and up to five saved ones. The health line has its own reserved height, so the late status never moves anything. **No privacy claim** ("nothing leaves this computer") is made on the home: the crawler talks to the network and some sources send queries out, and privacy wording is the owner's call. Its messages are in `search/home/messages`; the old `search_results_empty_{title,title_unknown,lead,saved}` keys are removed (`search_results_empty_focus` is still used by the index-state banner).
- **Recent searches (02 §4d).** One store: `search/assist/recent.ts`, now with `clearRecent()`. Home and the query bar's suggestions share it. They stay in this browser only. "Clear recent searches" on the home forgets them, and `signOut()` (every sign-out path, the palette's included) clears them too. A session that expires (401) is not a sign-out and keeps them.
- **Layout (P6).** At desktop the home takes the full width (no empty rail beside it), and its top padding goes so the band above it shrinks. "Clear all" showing in browse mode is out of scope (the results panel).
- **Health line (§10.4).** It is a link to Insights when something needs a look (paused, needs attention; to Settings for a pending restart), plain text when all is well. It reserves two lines below 640 px and one above, so a change of state never moves what is below it.
- **Recents between people.** Recent searches stay across a session expiry (401), which is not a sign-out, so someone else who signs in on the same browser would see them. This is an accepted refinement (runner, §2.19 flag): recents are this browser's, and Sign out clears them.
- **Files touched beyond the brief's owns, each small:** `results/messages` (the replaced empty-state keys), `results/testing.svelte.ts` (a status stand-in with a pill), `shell/glyphs.ts` (a magnifier), `insights/workers/workers.test.ts`, `e2e/status-stalled.routes.test.ts` and `e2e/search-toolbar.routes.test.ts` (an old pill word, and a Filters button that is now hidden on the home), and `.size-limit.mjs` (runner r14: the home entry, 2.49 KB, and the home counted as already loaded for later entries).
- **Left for the next brief touching the home:** the examples are still the three syntax examples carried over from the old empty state; §10.4 asks for plain-words and natural-phrasing examples and a quiet Syntax guide link, which waits for `/help/syntax` (X-help). The decisions file is dated 2026-11-23 (the brief said 11-22).
