# X-polish-1031d decisions

Optional findings from the #290 and #292 reviews. Nothing is loosened: a classification re-queue stays pending in as many cases as before, and past the cap it marks more torrents, never fewer. No schema, wire, setting or log-event change.

- **`classify.requeue_pending` is capped at 64 distinct query texts; past that it becomes one full re-mark** (`crates/api/src/filters.rs`, #290 O1).
  - **Why 64:** the value stays a few KiB, and it's read and rewritten under the store lock on every rule change. 64 is far above what an admin changes between starts with search off. Past it, marking everything costs less than remembering every text.
  - **Stored as the JSON string `"all"`,** not as a list item, so no query text can be read as it or clear it. Below the cap the list stays deduped.
  - **While it's pending:** a push is covered by it, a single text's clear leaves it, and with search on a rule change still marks its own matches at once.
  - **Clearing:** only `resume_requeues` at a start with search on runs it. It marks ids 1 to `Store::max_id` with the existing `mark_unenriched`, a `MARK_CHUNK` per store lock, checking the shutdown between chunks. It clears only once every chunk is done, with no shutdown and no rule change (`class_gen`) since it began: the same terms as a text entry. A torrent stored after `max_id` was read is enriched under the rules in force by then.
  - **A downgrade drops it:** an older binary reads `"all"` as unreadable and starts afresh. Downgrades aren't supported, and the same is true of a text entry an older binary never knew.
- **The soak report's memory columns say what they measure** (`docs/soak/tools/analyze_cr0.py`, #292). "Peak RSS (MiB)" is renamed "Peak working set (MiB)", since in Docker mode it's the cgroup working set, page cache included. A "Peak private (MiB)" column comes from `private_bytes` and reads unknown when the rows don't carry it. The JSON keeps `rss_max_mib` for older consumers and adds `private_max_mib`. The "RSS change" column is unchanged, since the brief named only the peak. Committed evidence reports aren't regenerated.
