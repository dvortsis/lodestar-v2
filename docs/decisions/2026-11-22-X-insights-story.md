# X-insights-story decisions (PR 1 of 2)

Builds on `2026-11-14-runner-ui-review-placement.md`. PR 1 covers U25, I25 + I9 + P14, P16, U26, the P10 cohort copy and 03-n (print). PR 2 (`slice/X-insights-story-stages`, after this merges) covers 03-q, the stage pages.

- **The strip and the KPI row stay separate (I25).** §10.9.1 makes the strip a process explainer and section navigation, and §10.9.2 / §10.9.6 make Status a KPI row of at most 5. The review's "merge them" would change both, so it is not done. Instead each strip tile names its time base (§10.9.3: "In this range", "By first harvest" for Discover, "Right now" for Index), which is the I9 fix.
- **One plain sentence opens the page (U25, D5).** It sits between the context bar and the strip, is built only from response fields (`kpi.health.state`, `kpi.new_searchable`, `exceptions.length`, the stalled verdict, `stale`, the startup state) and never says "working" or "Nothing needs your attention" unless they say so. Loading, error, stale, paused, starting, stalled and degraded each have their own line. The period is the selected range's phrase, never a fixed "this week". It is ordinary page text, so it also prints. The review's "everything else under Details" is not done as a collapse: the funnel and trend are the answer to "where are torrents lost", so they stay visible; the sentence and the existing Detail section carry U25's intent.
- **Order and layout follow §10.9.6 (P14).** Status, then trend 8 + needs attention 4 on one row, then the funnel 12, segments, Serve, Detail. On a narrow screen CSS `order` gives the plan's narrow order (exceptions, funnel, trend). When nothing needs attention, the trend takes the full row and the section is one line (I25).
- **Fewer boxes (P16).** Charts and number tiles keep their borders. The Detail links, annotations, import markers (overview only) and the paused/starting scenes drop theirs; headings and whitespace group them. The stage pages are untouched, so their size entry does not move.
- **Undo for the intensity click (U26, runner call).** The change applies at once. For 10 s after the last change a line under the control says what changed and offers Undo. Undo restores the level before that change; each change pushes the level it replaced, so two changes within 10 s undo one step at a time. The line is a `role="status"` region, so it is announced, and the button is an ordinary button. It is on the page, not in the shared toast queue, because the toast has no action button and `lib/ui` is not this slice's. It changes nothing about what the levels do.
- **Cohort rows read in words (P10).** "1,100 harvested, 520 searchable" replaces a bare count with a muted "520 searchable" beside it.
- **Print (03-n).** No change to `print/**` was needed: the print layout hides by test id, so the new order and the sentence print as they are. The print size entry is unchanged.
- **Size.** Nothing in `.size-limit.mjs` counts the overview's own JS and CSS. New overview-only styles are in `overview/overview.css`, not the shared `insights.css`, so the stage-pages entry stays at 40.65 KB of 40.66.
