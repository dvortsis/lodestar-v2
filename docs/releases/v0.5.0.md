# Lodestar 0.5.0 Release Notes

## Summary

Use this to decide whether to install Lodestar v0.5.0, the first release. Lodestar finds torrents on the [DHT](https://github.com/dvortsis/lodestar-v2/blob/main/docs/user/glossary.md#dht), the network BitTorrent programs use to find each other. It stores each torrent's description in a search index on your own server. It never downloads the content of a torrent and sends no telemetry.

## What Changed

### New

- **Crawler:** finds torrents on the DHT and fetches their descriptions: names, file lists, sizes and dates.
- **Search page:** a search box that colours your query, a filter sidebar with counts from your index, sorting, a Compact view, **Save search** and **Load more**.
- **Torrent details:** a side panel with the file list. Press **c** to copy the magnet link.
- **Keyboard use:** **/** jumps to the search box, and **Skip to results** jumps past the filters.
- **Also included:** the **Discover**, **Alerts** and **Compare** pages.
- **Content filters:** the child-safety core is always on. A change that weakens protection asks for your password first.
- **Install options:** an Unraid template, Docker Compose, and a template that routes Lodestar through a gluetun [VPN](https://github.com/dvortsis/lodestar-v2/blob/main/docs/user/glossary.md#vpn) container.

## Who Is Affected

Anyone installing Lodestar for the first time. If you ran a nightly build, take a backup before you switch, as in [section 3.7](https://github.com/dvortsis/lodestar-v2/blob/main/docs/user/03-keep-lodestar-safe.md#37-back-up-and-restore).

## Action Needed

From Oct. 24, 2026, the release date, before you open Lodestar for the first time:

1. Install it with [Chapter 2](https://github.com/dvortsis/lodestar-v2/blob/main/docs/user/02-install-lodestar-on-unraid-and-docker.md) of the guide. Put the data folder on an SSD or NVMe pool.
2. Copy the one-time setup token from the log and create the admin password straight away. Use a password manager.
3. Keep port 8090, the web page, off the internet. For remote access, use a VPN.

## Known Issues

- The Seeders and Trackers filters say **Not available yet**, and sorting by seeders isn't offered yet.
- The guide doesn't cover the search page yet.
- Unraid's Community Applications doesn't list Lodestar yet. Add the template by hand, as Chapter 2 shows.
- In-app updates aren't available yet. To update, back up, then pull the new image.
- The Windows installer is unsigned, so Windows SmartScreen warns. Check the file's checksum first, as [Chapter 4](https://github.com/dvortsis/lodestar-v2/blob/main/docs/user/04-install-on-windows-and-linux.md) shows.

## Get Help

Report a problem at <https://github.com/dvortsis/lodestar-v2/issues>. Don't paste logs with torrent details or your setup token into an issue.
