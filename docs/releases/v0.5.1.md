# Lodestar 0.5.1 Release Notes

## Summary

Lodestar v0.5.1 is the first public release. Lodestar finds torrents on the [DHT](https://github.com/dvortsis/lodestar-v2/blob/main/docs/user/glossary.md#dht) and indexes each torrent's description on your own server. It never downloads torrent content and sends no telemetry. After every start, sampling waits 6 hours, so new discoveries ramp up slowly and the index grows over days ([section 2.5](https://github.com/dvortsis/lodestar-v2/blob/main/docs/user/02-install-lodestar-on-unraid-and-docker.md#25-create-the-admin-password)).

## What Changed

### New

- **Crawler:** fetches names, file lists, sizes and dates from the DHT.
- **Search, details, Discover, Alerts and Compare.**
- **Content filters:** the child-safety core is always on.
- **Install options:** an Unraid template, Docker Compose and a gluetun [VPN](https://github.com/dvortsis/lodestar-v2/blob/main/docs/user/glossary.md#vpn) variant.
- **Deletion journal:** deleted torrents stay out of snapshots and backups.

### Changed

- **Faster crawler:** stalled lookups no longer hold slots. Much faster in the owner's uncontrolled soak; no exact figure.
- **Outbound policy:** no contact with private or special-purpose addresses learned from the network.
- **Honest status pill:** **Starting**, **Stalled** or **Idle**, and an **Insights** warning when the crawler stalls. Docker's health check only means the process is alive.
- **NAT64:** IPv6-only hosts can bootstrap from `64:ff9b::/96` and `64:ff9b:1::/96` seeds. The default DHT bind is still IPv4-only.
- **New metrics:** see `docs/metrics.md`.

### Fixed

- A failed password save no longer changes your credentials.
- Content filter, torrent parser and search-link fixes.
- If Lodestar can't save an update pause, the request fails (`updates_not_saved`) and updates stay held until a pause or resume is saved, or Lodestar restarts.

## Who Is Affected

Anyone who ran a pre-release or `:nightly`: the database migrates to V12 on first start, which older builds can't read.

## Action Needed

From Oct. 30, 2026:

1. From a pre-release or `:nightly`: run `lodestar backup` first, then pull the release image and start it ([section 3.7](https://github.com/dvortsis/lodestar-v2/blob/main/docs/user/03-keep-lodestar-safe.md#37-back-up-and-restore)).
2. Don't run `:nightly` on real data: it can apply migrations the release can't read.
3. New installs: follow [Chapter 2](https://github.com/dvortsis/lodestar-v2/blob/main/docs/user/02-install-lodestar-on-unraid-and-docker.md). Keep port 8090 off the internet, and create the admin password straight away.

## Known Issues

- uTP isn't active yet; its settings say **not active yet**.
- No import screen yet.
- Automatic updates are not available in this release. To update, back up and pull the new image.
- Community Applications doesn't list Lodestar yet; add the template by hand.
- The Windows installer is unsigned, so SmartScreen warns. Check its checksum ([Chapter 4](https://github.com/dvortsis/lodestar-v2/blob/main/docs/user/04-install-on-windows-and-linux.md)).

## Get Help

Report problems at <https://github.com/dvortsis/lodestar-v2/issues>. Leave out torrent-detail logs and your setup token.
