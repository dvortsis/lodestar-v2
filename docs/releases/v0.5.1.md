# Lodestar 0.5.1 Release Notes

## Summary

Use these notes to install Lodestar v0.5.1, the first public release, published at `2026-11-07T03:22:44Z`.

[Download v0.5.1](https://github.com/dvortsis/lodestar-v2/releases/tag/v0.5.1) or follow the [setup guide](../user/README.md).

## What Changed

### New

- **Local metadata search:** find torrent descriptions through the BitTorrent network and search them locally.
- **Web interface:** Search, torrent details, Discover, and crawler health on Insights.
- **Legal Notice v3:** setup shows the token step first, then the notice, then the password step. Read it again under **More → About**.
- **Packaged downloads:** Docker images for `amd64` and `arm64`, Windows `x86_64` MSI and portable ZIP, and Linux `x86_64` and `aarch64` archives.
- **Release verification:** `SHA256SUMS` and `SHA256SUMS.minisig` accompany the downloads. The Windows executable and MSI remain unsigned by Authenticode.

## Who Is Affected

Everyone installing v0.5.1 or upgrading from a release candidate. Pin Docker to `ghcr.io/dvortsis/lodestar-v2:0.5.1` to stay on this release.

## Action Needed

From 2026-11-07 at 03:22:44Z, before installing or updating:

1. Put the data folder on local SSD or NVMe storage. On Unraid, use a pool path such as `/mnt/cache/appdata/lodestar`.
2. Keep the web UI on your trusted network. Use a VPN for remote access; never forward `8090` on your router.
3. Back up an existing installation before replacing its image or binary. Follow [the backup and restore procedure](../user/03-keep-lodestar-safe.md#37-back-up-and-restore).
4. For a fresh installation, enter the setup token, read the Legal Notice, then create your admin password.
5. If you used an older candidate, accept the current notice when prompted after signing in.

v0.5.1 uses store schema V12. Earlier data may be upgraded on first start. A newer nightly can use a schema v0.5.1 cannot read.
Do not point v0.5.1 at a newer store; restore a compatible backup or use a new data folder.

## Known Issues

- DHT sampling waits six hours after every start, including restarts. Search remains available.
- Seeder and tracker filters show **Not available yet**.
- Add the Unraid template manually using [Chapter 2](../user/02-install-lodestar-on-unraid-and-docker.md); Community Applications listing is pending.
- In-app updates are unavailable. Back up, then replace the image or native package manually.
- The Sources screen, Sonarr and Radarr webhook setup, safe-restart switch, Magnetico import jobs, and pack-version controls are unavailable in v0.5.1.
- The five optional rule packs are off by default. Default-on packs and the unauthorised-copy pack are later work.
