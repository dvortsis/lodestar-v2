# Lodestar 0.5.1 Release Notes

## Summary

Use this to decide whether to install Lodestar v0.5.1, the first public release. Lodestar finds torrents on the [DHT](https://github.com/dvortsis/lodestar-v2/blob/main/docs/user/glossary.md#dht), the network BitTorrent programs use to find each other. It stores each torrent's description in a search index on your own server. It never downloads the content of a torrent and sends no telemetry.

## What Changed

### New

- **Crawler:** finds torrents on the DHT and fetches their descriptions: names, file lists, sizes and dates.
- **Search page:** a search box that colours your query, a filter sidebar with counts from your index, sorting, a Compact view, **Save search** and **Load more**.
- **Torrent details:** a side panel with the file list. Press **c** to copy the magnet link.
- **Keyboard use:** **/** jumps to the search box, and **Skip to results** jumps past the filters.
- **Also included:** the **Discover**, **Alerts** and **Compare** pages.
- **Content filters:** the child-safety core is always on. A change that weakens protection asks for your password first.
- **Install options:** an Unraid template, Docker Compose, and a template that routes Lodestar through a gluetun [VPN](https://github.com/dvortsis/lodestar-v2/blob/main/docs/user/glossary.md#vpn) container.

### Improved since the pre-releases

- **A faster crawler:** stalled lookups no longer hold on to slots, and the crawler's internal lifetimes now line up. In the owner's soak test it was much faster. The test wasn't controlled, so there is no exact speed-up figure.
- **An outbound network policy:** Lodestar won't contact private or special-purpose addresses that it learned from the network.
- **A deletion journal:** torrents you delete stay out of snapshots and backups.
- **Search links** that aren't in their standard form now load results.
- **A status pill that tells the truth:** it shows progress and warns when the pipeline has stalled. <!-- confirm at release cut: F-status wording and states -->

### Fixed

- **Passwords:** a failed password save no longer changes your credentials.
- **Content filters:** per-list exceptions, rules that match a stored hash, and **Neutralize** inside phrases and `NEAR` queries now work as set. Neutralize is also faster.
- **Torrent parser:** fixes for how Lodestar reads torrent descriptions.

## What to Expect in the First Hours

- **Search works at once.** New discoveries come slowly at first.
- **After every start, sampling waits 6 hours before it resumes.** This keeps Lodestar polite to other DHT nodes (BEP 51). It applies to restarts and updates too, so discoveries ramp up over the first hours after each one.
- **The index grows over days,** not minutes. Leave Lodestar running.

## Who Is Affected

- **New installs:** nothing to do beyond the install guide.
- **Anyone who ran a pre-release or the `:nightly` image:** the database migrates to schema V12 on first start, and an older build can't read it afterwards.

## Action Needed

1. **Upgrading from a pre-release or `:nightly`:** take a backup first with `lodestar backup`, as in [section 3.7](https://github.com/dvortsis/lodestar-v2/blob/main/docs/user/03-keep-lodestar-safe.md#37-back-up-and-restore). Then pull the release image and start it.
2. **Don't run `:nightly` on real data.** It can apply database migrations that the release can't read.
3. New installs: follow [Chapter 2](https://github.com/dvortsis/lodestar-v2/blob/main/docs/user/02-install-lodestar-on-unraid-and-docker.md), keep port 8090 off the internet, and create the admin password straight away.

## Known Issues

- **uTP isn't active yet.** The transport setting says **not active yet** and has no effect. <!-- confirm at release cut -->
- **There is no import screen yet.**
- **Automatic updates are not available in this release.** To update, back up, then pull the new image. <!-- confirm at release cut: runner may change this -->
- The Seeders and Trackers filters say **Not available yet**.
- Unraid's Community Applications doesn't list Lodestar yet. Add the template by hand, as Chapter 2 shows.
- The Windows installer is unsigned, so Windows SmartScreen warns. Check the file's checksum first, as [Chapter 4](https://github.com/dvortsis/lodestar-v2/blob/main/docs/user/04-install-on-windows-and-linux.md) shows.
