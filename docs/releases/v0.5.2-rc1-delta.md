## Default-on behaviour the release notes leave out

These are in the build and on by default. The release notes leave them out to stay within the cap (runner, 2026-11-07); each is in manifest §9.1:
- **Workers API:** the `/api/v1/workers*` routes are registered. They need a session; `GET` answers `allowed:false`, and every action answers `409 workers_off`. No route turns workers on (#573).
- **Turning a source off:** in Settings → Sources this now stops it at once, the DHT included (#525). The notes say so for sources in general.
- **Zero-valued metrics:** about 30 `lodestar_cluster_*` and `lodestar_remote_*` families always read 0. The new non-zero series are `fetch_held_bytes`, `fetch_held_full_total` and `lodestar_mem_anon_mappings{size}`.
- **The API:** `GET /sources` gains `credential_spec` and `config_schema`, and there's a new `GET /sources/{id}/purge/preview` (#561).

## In-app updates under the supervisor

**The release image runs `serve` under the supervisor:**
- `packaging/docker/Dockerfile` ends `ENTRYPOINT ["/lodestar"]` and `CMD ["serve"]`.
- On Unix, `serve` without `--child` always runs `update::supervisor::run` (`crates/lodestar/src/main.rs:151-161`). It's behind `#[cfg(unix)]`, not a Cargo feature, so the release build (`--no-default-features --features web`) has it.
- The supervisor then starts the server as `serve --child`. Install now and Roll back go through it.
- **Seen on a real build (2026-11-07T16:25Z):** the release-feature binary was built from this branch with `cargo build --release --locked -p lodestar --bin lodestar --no-default-features --features web` and reports `lodestar 0.5.2`. Run as `lodestar serve`, its process tree was `lodestar serve` (the supervisor) with one child, `lodestar serve --child`. On `SIGTERM` the child logged `app.stopped_cleanly` and the supervisor exited 0.
- **The image's own smoke on #582's CI** (`smoke (linux/amd64)`): three containers of the release image ran `serve`, came up healthy and exited 0 after `docker stop`.
- **What neither run did:** install an update. That needs a signed release to download, and none exists before the tag. The supervisor's install and rollback paths are covered by `crates/lodestar/tests/supervisor.rs`.
- **The claim stays in the release notes.**
