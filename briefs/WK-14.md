## Do
1. **Endpoints, admin only,** all under the existing auth middleware:
   - **`GET /workers`:** from `ClusterServer::snapshot` plus the saved prefs. Fields as §19.7 lists them, where the snapshot has them now. Leave fields from later slices out, rather than faking them.
     - No peer addresses, no certificate private material, and no tokens.
     - External IP is shown, because §19.7 asks for it. It's the worker's own egress, not a peer.
   - **`POST /workers/tokens`:**
     - creates a one-time `lsj1` join token through the existing join code (15 min, single use, name-bound, stored hashed);
     - returns it **once**, with the ready-to-copy commands from §19.6 (CLI, `docker run` and compose; the Unraid and Windows lines can be text);
     - the token never appears in any other response, in a log, or in an error.
   - **`POST /workers/{id}/drain`, `/resume`, `/pause`.**
   - **`POST /workers/{id}/revoke`:** a Danger zone action (§10.10.7).
     - It invalidates the certificate at once and returns the worker's leases. It ends in "gone within one heartbeat".
     - The response says what revoke did: how many leases were returned.
   - **`PATCH /workers/{id}`:** budget, intensity and DHT pins, each with validated ranges.
2. **`crates/lodestar/src/cluster/ops.rs`:** the glue between the API and `ClusterServer`/placement. The API crate must not reach into cluster internals.
3. **The #560 delta-review items** (WK-5's hand-offs; each one is a gate with a test):
   1. **Persist worker prefs** (pin, budget, intensity) and re-apply them after a coordinator restart. Use the settings store or an existing table. **If it needs a schema change, message the runner first**, because WK-12 holds the migration slot.
   2. **Disconnect before `Placement::forget`.** Otherwise the next tick rejoins with defaults. Revoke must do it in that order.
   3. **A join refused at `MAX_WORKERS` (4,096):** warn and don't record its addresses, so it's retried later.
   4. **`prefs_mut` silently refuses a pin when it's full:** surface that as an error the API returns (409 or 422, as the API's error conventions say).
   5. **`is_public`:** add `2001:2::/48` (benchmarking) and `3fff::/20` (documentation), with tests.
4. **The decisions file:** `docs/decisions/2026-11-07-WK-14.md`, with notes for WK-13 (where quarantine, release and purge plug in) and WK-16 (the screen). Name every §2.19 refinement.
