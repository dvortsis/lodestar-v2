## Build
1. **`GET /suggest?q=<partial>&limit=`** (default 8, max 20). It takes the query text and the caret position (`pos`, default end), finds the token being typed, and returns typed suggestions:
   - **field names** (`res:`, `ext:` …) for a partial `x`, from the query language's own field table (never a second list);
   - **field values** after `field:` from the term dictionary of that field (resolutions, extensions, languages, groups, codecs …), with document frequencies, prefix-matched;
   - **titles** from a parsed-title FST (prefix, ranked by frequency/popularity, deduplicated case-insensitively);
   - **smart chips**: a recognised bare token (`2160p`, `x265`, `mkv`, `2020`) offered as its field form (`res:2160p`), reusing the parser/classifier's recognisers;
   - **did you mean**: when the whole query has few or no hits, fuzzy (Levenshtein ≤ 1–2 by length) alternatives from the term dictionaries, and the existing unknown-field "did you mean".
   - Each item: `{kind, text, insert, replace: {start,end}, count?}`, where `replace` is a char range in the query, so the client never re-tokenises.
2. **Visibility and safety.** Suggestions must never leak what the base query hides: titles and values that occur only in hidden-by-filter or (when Adult is hidden) Adult torrents are not suggested. Choose the mechanism (a per-visibility FST, counts under `BaseQuery::visibility`, or filtering candidates by a cheap existence check on the lease) and test it with an Adult-only title and a filter-hidden title. Sealed names (§20) are never suggested.
3. **The FST** lives beside the index (not in the Tantivy schema), is rebuilt incrementally or periodically off the commit path, survives a B5b rebuild/swap (it's rebuilt for the new directory), and has a memory budget stated in the PR (measure at 1M titles).
4. **Natural phrasing on `/parse`:** `POST /parse` (or the existing endpoint) gains `natural: true`, which returns a proposed canonical query plus the chips it would add (`4k movies from 2020 over 10gb` → `res:2160p type:movie year:2020 size:>10GB`), never applied server-side. Deterministic, rule-based, bounded input length; unrecognised words stay as text. Golden tests for at least 30 phrasings, and property tests that the output always parses and round-trips through the canonical renderer.
5. **Budget:** `/suggest` p95 < 15 ms at 1M documents. Add a `suggest` class to `search-bench` and gate it at 200k like the others; report the 1M number.
6. **Cancellation:** the request's cancel token is honoured; a stale request costs nothing once the client aborts.
