## What to build
1. **Compose** (`compose.rs`): a `docker compose` service block per companion, optionally a gluetun service with the companion on `network_mode: service:gluetun`.
   - Built **only** from catalogue values and CMP-0's closed input types. No free-form string reaches the output.
   - Every YAML key and scalar is emitted quoted through `serde_json` (JSON is valid YAML). No string concatenation of values, and no hand-written escaper.
   - The image is pinned by digest (`image@sha256:…`).
   - Ports are bound to the internal network or `127.0.0.1` by default; exposing one on the LAN needs an explicit input.
   - **No Docker socket mount, ever,** and no `privileged`, `cap_add` beyond what gluetun's upstream docs require (`NET_ADMIN`, plus `/dev/net/tun`; justify each in the decisions file), no `pid: host` and no `network_mode: host`.
   - **gluetun's VPN keys stay placeholders.** Lodestar never asks for or stores them. The output marks them for the user to fill in, with a comment saying so.
   - TZ and UMASK: closed types or fixed values (slices.yaml note).
2. **Host paths under Docker.** Lodestar sees `/data`, not the host folder. Take the host path from the Unraid template value or from the user, including the optional hot and cold paths, as a closed `HostPath` input. Check it against the instance's real data folder where that's knowable, and refuse a relative path, `..`, or a path that isn't absolute.
3. **Unraid** (`unraid.rs`): the template XML through `quick-xml`'s writer, never by concatenation. Fields match `packaging/unraid/` conventions. Per Q11: a pre-filled template link if Community Applications supports it, otherwise the template file plus the values to copy.
4. **Packaging snippets** (`packaging/companions/**`): the example compose files and Unraid templates generated by this code. A test checks they're byte-identical to what the code generates, so they can't drift.
5. Errors are typed codes. No `unwrap` or `expect` outside tests.

## Tests and gates
- **Golden tests per companion,** with and without gluetun, for compose and Unraid.
- **A property test:** no input value can add a YAML key, a second document, an anchor or alias, or an XML element or attribute. Try newlines, `: `, `---`, `&`, `*`, `<`, quotes and NUL in every input newtype that accepts text.
- **Refusals:** a relative host path, `..`, and an out-of-range port.
- No fixed sleeps.
- **Before pushing:**
  - `cargo fmt --check`;
  - `cargo clippy --workspace --all-targets -- -D warnings`;
  - `cargo test -p lodestar-companions`.
- **Size:** about 700 lines per the plan; stay under 1,500, or state why.
