## Why
1. **Size.** All server `settings_*` labels sit in one static `MESSAGES` map (`web/src/lib/features/settings/form/message-map.ts`, generated by `message-map.gen.ts`) inside the engine chunk. Every engine-backed section's first view is now about 43.1 KB against the **owner-set 45 KB** per-route cap (§10.1; "Settings section" in `web/.size-limit.mjs`). Four more screens' labels would push it over.
2. **Bug.** In `SettingField.svelte` (around lines 45–81), in instant mode, turning **Automatic** off on a field whose `x-auto` value is `""` snaps straight back on. The effect re-arms `manual = false` whenever the value equals the auto value. #259 worked around it by dropping `x-auto` on Language & region's language and time-zone fields.
