## Do
1. **`crates/lodestar/src/cluster/testing.rs`**: a harness, compiled for tests only (`#[cfg(any(test, feature = …))]` only if an existing feature fits; never a tokio `test-util` or `testing` feature on the `lodestar` package). It provides:
   - one coordinator and N workers in one process, each worker with its own data dir, credentials and spool, joined through the real join path;
   - the shared test `Clock`, with per-node skew;
   - injectors:
     - **kill a worker** (abrupt drop, no clean shutdown) and **restart it** from its saved credentials and spool;
     - **partition**: cut a worker's link both ways or one way, and heal it;
     - **restart the coordinator** on the same store;
     - **clock skew**: move one node's clock forward or back;
   - **a funnel reconciler**: harvested = Σ terminal outcomes + in flight, from the store and the coordinator's counters, plus a "no key fetched by two workers outside a lease expiry" check from a per-key fetch log the harness records;
   - condition waits only (`wait_until(deadline ≥ 10 s, …)`), never fixed sleeps.
2. **`crates/lodestar/tests/cluster_chaos/`**: one integration test binary with a small set of scenarios proving the harness works. Each runs in seconds:
   - kill and restart a worker mid-lease: its keys are re-leased after expiry, and the funnel reconciles;
   - partition and heal: stale-token outcomes from the partitioned worker are ignored (fencing);
   - coordinator restart: workers reconnect, and the funnel reconciles;
   - a skewed worker clock beyond the allowed offset is refused cleanly.

   These are smoke tests of the harness. WK-G owns the full §19.8 gate tests (`cluster_gate.rs`) on top of it, so keep the API easy for WK-G to drive and document it at the top of `testing.rs`.
3. **Decisions file** `docs/decisions/2026-11-11-WK-20.md`:
   - the harness API;
   - how each injector works;
   - what WK-G can and can't test with it (for example, per-remote-IP politeness needs a recording fake peer);
   - anything you found missing in the runtime that WK-G will need.
