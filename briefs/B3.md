# B3: Embedded SPA serving, CSP, and the status page moved to /status
**Model:** Opus (core: security headers, serving). **Branch:** `slice/B3`.
**Spec, in order of authority:**
- `docs/owner-decisions.md`, then `runner/standards.md` (branch `runner/standards`, PR #39, until it merges), then CLAUDE.md;
- architecture §10.1 (the SPA is embedded in the binary, precompressed with brotli; asset filenames content-hashed with immutable caching), §11 (one binary), §12 (CSP and security headers);
- web/ on main: W0 scaffold, W1 themes, W2 tokens and fonts; adapter-static with `fallback: 'index.html'`.

## Do
1. **Build integration:** `crates/lodestar/build.rs` (or a small crate) embeds `web/build/` when it exists and the `web` cargo feature is on (default on for release builds).
   - When `web/build` is absent, compile a stub page saying "UI not built: run `npm run build` in web/", so `cargo test` needs no Node.
   - Precompress every text asset at build time with brotli and gzip, choosing by `Accept-Encoding`, with `Vary: Accept-Encoding`.
   - Use one maintained crate (rust-embed or include_dir plus a compression crate), approved and pinned the way the workspace does it. Measure and report the binary size increase.
2. **Serving** (`crates/lodestar/src/web.rs`, wired in `http.rs`):
   - `/_app/immutable/**`: `Cache-Control: public, max-age=31536000, immutable`.
   - `/brand/**`, `/fonts/**` and `/themes.json`: these are **not content-hashed**, so use short caching (`max-age=3600`, plus ETag).
   - `index.html` and the SPA fallback: `no-cache`.
   - The SPA fallback serves index.html for unknown non-API GET paths. `/api/**`, `/metrics`, `/healthz` and `/status` are never shadowed, and unknown `/api/**` paths keep the envelope 404.
   - Correct content types, and no directory listing or path traversal (test `..`, encoded and doubled slashes).
3. **CSP and headers on every HTML response:**
   - `default-src 'self'`;
   - `script-src 'self' 'sha256-…'`, with the pre-paint inline script's hash **computed at build time from the built index.html** (not hard-coded);
   - `style-src 'self'` (check whether Svelte, daisyUI or fonts need anything more and justify it);
   - `img-src 'self' data:`, `font-src 'self'`, `connect-src 'self'`;
   - `frame-ancestors 'none'`, `base-uri 'none'`, `form-action 'self'`;
   - plus `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer` and `Permissions-Policy` with sensible denies.

   Keep the existing status page's own CSP working.
4. **Move the status page** from `/` to `/status`, behind the same auth as before. `/` now serves the SPA.
5. **Tests:** cache headers per class; the fallback; API not shadowed; traversal attempts; encoding negotiation; the CSP hash matching the built inline script (test with a fixture build dir); the stub when web/build is absent.

## Don't
- Change the API, auth or the web app code.
- Touch crates/api.

## Done when
- fmt, clippy (`--all-targets -D warnings`) and the workspace tests pass, with and without `web/build` present (run `cd web && npm ci && npm run build` for the "with" case).
- A Playwright smoke run against the binary, if it fits: start `lodestar serve` on a temp data dir, load `/`, and check there are no CSP violations in the console. Otherwise describe a manual check in the PR.
- A §16 entry records the caching classes and the CSP.
