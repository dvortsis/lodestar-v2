# W2: Tokens, daisyUI mapping, font subsets, and the spacing-step ban
**Model:** Sonnet (helper). **Branch:** `slice/W2`.
**Spec, in order of authority:**
- `docs/owner-decisions.md`, `runner/standards.md` (§3 design skills, §4 UI rules);
- architecture §10.2 (spacing, grid, typography, geometry, icons, motion, colour use), §10.1 (budgets: CSS ≤ 20 KB; fonts on first paint ≤ 35 KB; Atkinson Hyperlegible Next variable, Latin subset, preloaded; Mono lazy ≤ 25 KB) and §10.18 (the daisyUI 5 mapping);
- `docs/design-tokens.md`, **the contract**: every static token (§5 spacing allowed steps, §6 geometry, §7 density/layout/breakpoints, §8 typography, §9 motion) and the daisyUI variables;
- for gaps only, ui-design-skills: `layout-spacing`, `typography-ui`, `component-geometry`, `motion-ui`, `application-interface-design`.

The theme compiler (W1, merged) already emits the colour tokens into `src/lib/theme/critical.css`. Don't change colour derivation.

## Build
1. **`web/src/app.css` and `web/src/lib/theme/tokens.css`:**
   - Tailwind v4 `@theme` with exactly the static tokens in design-tokens.md §5–9: radii (`--radius-box: 12px`, `--radius-field: 8px`, `--radius-selector: 4px`, plus the single 16 px dialog/drawer override), control heights, type scale (6 steps, size/line-height), weights 400/500/600, motion durations and easings, breakpoints, layout widths, density row heights.
   - **Spacing keeps Tailwind's default `--spacing` (0.25rem).** Don't redefine it.
   - daisyUI 5 configured with `themes: false`, or a minimal setup, so that the compiler's variables drive all colour; no daisyUI built-in theme CSS ships.
2. **Fonts:**
   - Self-host Atkinson Hyperlegible Next (variable) as a woff2 **Latin subset**, ≤ 35 KB, with `<link rel=preload>` in `app.html`. Atkinson Hyperlegible Mono is a Latin subset, ≤ 25 KB, lazy (no preload; `font-display: swap`).
   - The Latin-Extended subset loads on demand via `unicode-range`.
   - Fallback stacks per §10.2, including CJK.
   - Subset with a build step (e.g. `subset-font` or `glyphhanger`), as a pinned devDependency; this one is approved. Output to `web/static/fonts/`.
   - Verify `font-variant-numeric: tabular-nums` works with the subset (a test that the `tnum` feature survives subsetting).
3. **Ban extension (owner-approved spacing rule):** extend `web/scripts/bans.mjs` and the ESLint rule to reject Tailwind spacing utilities whose step isn't in the allowed list (0, 0.5, 1, 1.5, 2, 2.5, 3, 4, 5, 6, 7, 8, 9, 10, 12, 13, 14) for p/m/gap/space/inset/top/right/bottom/left/w/h-style spacing utilities. Width and height utilities for layout use tokens, so document how fixed sizes are expressed (named layout tokens, not steps).
   - Add tests: `p-11` fails, `p-12` passes, `gap-0.5` passes.
   - Don't weaken the existing hex and arbitrary-value bans.
4. **size-limit:** add the font budget entries (first-paint fonts ≤ 35 KB; Mono ≤ 25 KB). The total first load (JS + CSS + preloaded font) stays ≤ 100 KB.
5. **A token showcase route for tests only** (`src/routes/_dev/tokens/+page.svelte`, excluded from the production build or behind a dev flag). It renders type scale, radii and control heights. Add a Playwright visual snapshot of it in Riverstone light and dark.

## Don't
- Build components (W7), change colours, or add other dependencies.

## Done when
- `npm ci`, `npm run check`, `npx vitest run`, `npm run build`, `npx size-limit` and `npx playwright test` pass.
- CSS ≤ 20 KB; fonts within budget.
- The PR lists every token it emits, mapped to design-tokens.md.
