# W8: One formatter per metric
**Model:** Sonnet (helper). **Review:** line by line. **Branch:** `slice/W8`.
**Spec:**
- `runner/standards.md` (the build bar for every slice; §3 covers the design skills);
- `ui-design-skills` (`git clone --depth 1 https://github.com/dvortsis/skills`, then `ui-design-skills/skills/<name>/SKILL.md`): `data-visualization-design` (by spirit: data contracts, states, the single formatter per metric), `analytics-chart-selection` (formatting, axes, labels) and `analytics-validation`;
- `docs/metrics.md` (merged in C0). **§1 value states, §2 time bases, §3 formatters and §5a histograms are the contract.** Every example in §3 is the exact Node 22 output for en and zh, and your tests must reproduce them byte for byte.
- architecture §10.12;
- `docs/ui-glossary.md` for labels.

## Build
- **`web/src/lib/format/`**: one module per formatter named in metrics.md §3, with exactly the `Intl` options it specifies. Cache one `Intl.NumberFormat` / `DateTimeFormat` / `RelativeTimeFormat` instance per locale and options; construction is expensive.
- **Null ≠ zero:** `null`/`undefined` → "—"; a real 0 → "0"; estimated → the "≈" prefix; sampled → "≈" plus the note key from metrics.md §1.
- **Number details:** IEC bytes with the fixed decimal places by magnitude, U+2212 minus, `hourCycle: 'h23'`, and percent precision and `<`/`>` edges exactly as written.
- **Locale:** take it as a parameter, defaulting to `en`. When W4 lands, `currentLocale()` will be passed in; don't import W4 code.
- **Histogram bin edges** for size (log bins with labelled edges), per §5a: a pure function returning edges and labels.
- **No dependencies, no hex, no DOM access.** These are pure functions.

## Tests
- A table-driven vitest suite with **every example in metrics.md §3 and §5a**, in en and zh, byte-exact.
- Plus null, 0, negative, NaN/Infinity (render "—" and never throw), very large values (PiB, 10^12 counts), and boundary values at each unit switch.

## Done when
- `npm run check`, `npx vitest run` and `npm run build` pass.
- `npx size-limit` passes. Formatters are tree-shaken, so only imported ones count.
- The PR description lists any metrics.md example you believe is wrong, with the actual Node output. Don't change the doc; the runner decides.
