## Build
1. **`GET /crawler`, `POST /crawler/pause`, `POST /crawler/resume`, `PATCH /crawler {intensity}`:**
   - **Pause** stops harvesting and metadata fetching: the DHT crawler stops issuing sample/get_peers traffic and the fetch pool stops starting new fetches.
     - In-flight fetches finish or time out normally.
     - The DHT node keeps answering other nodes' queries (a good DHT citizen) unless §5/§6 says otherwise.
     - Indexing of already-fetched data continues.
     - Pause and resume are idempotent.
     - **Persist** the paused state (it survives restart) through B2's registry. Add a `crawler.paused` field if it isn't there; pause/resume is how it changes.
     - Record an `events` row on each pause and resume (kind = pause/resume), so Insights can annotate gaps.
   - **Intensity** goes through B2's registry, the same path as `PATCH /settings/crawler`. One source of truth; no second store. This endpoint is a convenience for the global bar. Record a config/intensity-change event.
   - **Status:** running/paused, since, intensity, the DHT node's state (bootstrapped, routing-table size), and the fetch pool's in-flight/queue.
2. **`GET /stats`:** the summary the global bar and status pill need: searchable torrents, stored torrents, the harvest rate, the fetch rate, queue depth, index lag (s), disk used and free on the data volume, uptime.
   - Every field is defined in `docs/metrics.md` (add rows if missing), with units.
   - **null ≠ 0:** a value that can't be measured right now is null.
   - Read the same counters `/metrics` and the status page use; never a second count.
3. **`GET /sources` and `PATCH /sources/{id}`:**
   - List the registered sources and plugins with id, kind, consent class, enabled/disabled, priority, schedule and health (last run, last error, items).
   - `PATCH` enables or disables one and sets priority.
   - **Enforce** disabled/paused: the M2 note says stored states aren't enforced yet. Make the scheduler or plugin runner skip disabled sources, with a test.
   - Consent: enabling a source whose consent class requires explicit consent (§18) must require a `consent: true` field naming the class, or a 409 with a clear code. Don't invent new consent classes; use what `crates/sources` defines.
   - Leave agents, egress, purge and the schedule editor for the v0.6 sources epic, typed as not yet editable, and say so in §16.
4. **The network check** (wizard step 3, and a dashboard "reachable" flag): `GET /network/check`, or part of `/crawler` status. It reports:
   - **External address and port** as other DHT nodes see us: the KRPC `ip` field (BEP 42) votes; report the consensus and the number of voters.
   - **Reachable:** whether unsolicited inbound DHT queries are arriving on the DHT port (a counter of inbound queries from nodes we didn't contact first, over the last N minutes). Report `reachable: true/false/unknown`, with the evidence counts and a short reason, and `unknown` until enough time has passed (e.g. 2 minutes after bootstrap).
   - **UPnP/NAT-PMP mapping status**, if the binary has it. Otherwise `unavailable`.
   - **No third-party "port check" service.** Every probe uses the DHT itself, so nothing leaves beyond normal DHT traffic (§18.7).
   - `POST /network/check` restarts the measurement window (rate-limited).
5. **Security:** every route is behind `auth::protected`, and writes are same-origin JSON like the other write routes. Pause/resume needs no password; it's an operational control, not a filter change.

## Tests
- Pause stops new harvest and fetch starts within a bound, and the DHT still answers queries.
- Resume restarts them.
- The paused state survives a restart (store reopen).
- Events rows are written for pause, resume and intensity changes.
- Intensity through `/crawler` and through `/settings/crawler` stay one value.
- `/stats` fields equal the `/metrics` counters on a fixture, and null where unmeasurable.
- Sources: a disabled source is skipped by the scheduler; the consent requirement; an unknown id gives 404.
- Network check: the `ip` votes are tallied (BEP 42 parsing from untrusted KRPC: bounded, malformed input ignored); inbound unsolicited queries flip `reachable`; it's `unknown` before the window.
- API goldens; unauthenticated gives 401; a cross-origin write gives 403.
