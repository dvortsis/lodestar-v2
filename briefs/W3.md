# W3: Brand asset pipeline
**Model:** Sonnet (helper). **Branch:** `slice/W3`.
**Spec:**
- architecture §10.19 (all: pack contents, repository placement, the asset pipeline, favicons and PWA, where each asset is used, the illustration rules) and §10.17 brand asset gates;
- `brand/source/` (originals plus `SHA256SUMS.txt`; `visuals/manifest.json` lists the scenes and their aliases).

## Build
1. **`web/scripts/assets.ts`**, using **sharp**. This is the one new dependency approved for this slice: add it as an exact-pinned devDependency.
   - **Verify the source pack first:** `brand/source/SHA256SUMS.txt` must match every file. Fail on any mismatch or any missing file.
   - **State scenes:** the 14 PNGs in `visuals/` → AVIF and WebP at 360, 540 and 724 px wide, in `web/static/brand/scenes/`.
     - Gate: every AVIF at 540w must be ≤ 45 KB. The build fails otherwise, with a report listing each file and its size.
     - Write `web/src/lib/brand/scenes.generated.ts` with `{ id, mode, width, height, srcset: {avif, webp} }`, so components set `width`/`height` and can't cause layout shift. Keep the aliases (`found_nodes` → `searching_crawling`, `offline_idle` → `welcome_onboarding`).
   - **Logo lockups:** trim each one, then AVIF and WebP at 1× and 2× of their display size (wordmark 240 px wide; horizontal and stacked per §10.19), into `web/static/brand/logos/`.
   - **Compass SVG:** minify `icons/compass_{light,dark}.svg`, then rewrite the fills to CSS variables `var(--brand-surface, …)`, `var(--brand-primary, …)`, `var(--brand-accent, …)` and `var(--brand-star, …)`, with the Riverstone values as fallbacks. Output one ~0.5 KB inline mark in `web/src/lib/brand/compass.svg`.
   - **Favicons:**
     - copy the `.ico` and the apple-touch icon;
     - make an SVG favicon with a `prefers-color-scheme` swap;
     - fix the icon paths in `site.webmanifest` to `/brand/favicons/…`;
     - put everything in `web/static/brand/favicons/`.
   - **Packaging icons** (used later by M6): a multi-resolution Windows `.ico` (16–256) from `mascot_app_dark_256`, plus the 256 px PNG for Unraid, in `packaging/icons/`.
   - **Cache:** skip work when a hash of the inputs is unchanged, so repeat builds are fast.
2. **Add `<head>` tags** to `web/src/app.html`: the SVG favicon, `.ico` fallback, apple-touch icon, manifest, and `<meta name="theme-color">` per scheme (Riverstone values). Make only those edits. W1 also edits `app.html` (the pre-paint script); merge `origin/main` if you collide.
3. **Package script:** exactly one line, `"assets": "…"`, run from `prebuild` alongside any existing prebuild step. If another slice also edited the scripts block, merge `origin/main` and keep both.
4. **Tests** (vitest):
   - the checksum mismatch path;
   - the 45 KB gate;
   - every generated scene entry has width and height;
   - the compass output contains no hex outside `var()` fallbacks.

## Don't
- Write UI components that display the art. W9 does that.
- Add raster art to the first-load bundle. Add a size-limit assertion that no brand raster is in the first-load chunk set, if `.size-limit.mjs` makes that easy; otherwise note it for W6.

## Done when
- `npm run assets` passes on a clean checkout.
- The total size of `web/static/brand/` is reported in the PR description (§10.19 expects about 1–1.5 MB of variants).
- `npm run check`, `npx vitest run`, `npm run build` and `npx size-limit` pass.
