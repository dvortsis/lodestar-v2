# Graded judgments for the relevance suite (bench/README.md, "Relevance").
#
# `? query` as typed in the search box; `= rationale`, one line on what
# the ideal results are and why; then grades:
#   3  exactly what the query asks
#   2  a right answer (another good release of it)
#   1  related, acceptable further down
#   0  judged not relevant (the same as unjudged)
#   x  must never be shown (hidden Adult, a negated word, a scoped field)
#
# Judgments describe the ideal ranking, not today's: a family whose
# ideal needs a phase-2 feature that hasn't landed (swarm priors, the
# junk penalty) scores below 1 until it does.
