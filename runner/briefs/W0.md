# W0: Web scaffold
**Model:** Sonnet (helper). **Branch:** `slice/W0`.
**Spec:**
- architecture §10.0, §10.1 (stack and budgets), §10.3 (routes), §13 (layout);
- `docs/build-plan.md` §1.3 (pinned dependencies, per-feature messages, lint bans);
- the skills repo `https://github.com/dvortsis/skills` (public; clone it read-only), `ui-design-skills/skills/application-interface-design/SKILL.md`.

## Create `web/`
- **Base:** SvelteKit 2, Svelte 5 runes, TypeScript strict, `@sveltejs/adapter-static` with `fallback: 'index.html'`, `ssr = false` and `prerender = false` in the root `+layout.ts`.
- **Pinned dependencies**, exact versions with no `^`. These were checked on npm on 2026-10-22; use them or newer patch releases:
  - styling: tailwindcss 4.3.x with `@tailwindcss/vite`, daisyui 5.7.x;
  - UI libraries: bits-ui 2.20.x, @tanstack/svelte-virtual 3.13.x, uplot 1.6.x (installed only, lazy-imported later);
  - icons: unplugin-icons 24.x with @iconify-json/ph;
  - i18n: @inlang/paraglide-js 2.29.x;
  - fonts: @fontsource-variable/atkinson-hyperlegible-next and @fontsource-variable/atkinson-hyperlegible-mono 5.3.x;
  - API types: openapi-typescript 7.13.x (dev);
  - tests: vitest + @testing-library/svelte + jsdom, @playwright/test with @axe-core/playwright;
  - budgets: size-limit with @size-limit/preset-app, @lhci/cli 0.15.x;
  - tooling: eslint 9 flat config with eslint-plugin-svelte, prettier with prettier-plugin-svelte, svelte-check.
  - Playwright: **never** run `playwright install`. Chromium is at `/opt/pw-browsers`, and `PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1` is set.
- **Directory skeleton** with README stubs explaining what goes where (§10.11 rules: dependencies point one way, ui → features, never the reverse):
  - `src/lib/ui`, `src/lib/features`, `src/lib/charts`;
  - `src/lib/api`, `src/lib/state`, `src/lib/format`;
  - `src/lib/theme`, `src/lib/shell`, `src/lib/keys`.
- **One empty `+page.svelte`** (a heading only) for every route in §10.3:
  - `/` redirects to `/search`;
  - `/search`, `/t/[hash]`, `/compare`, `/discover`;
  - `/alerts`, `/alerts/[id]`;
  - `/insights`, `/insights/[stage]`;
  - `/settings/[section]`;
  - `/setup`, `/login`, `/welcome`.
- **Lint bans:** an ESLint rule, plus a small script run in `npm run check`, that fails on hex colour literals and on Tailwind arbitrary values (`[#…]`, `-[13px]` and similar) in `src/**/*.svelte` and `src/**/*.ts`. Exempt `src/lib/theme/**` and generated files.
- **Scripts:** `dev`, `build`, `check` (svelte-check + eslint + the ban script), `test` (vitest), `e2e` (playwright), `size` (size-limit), `api:types` (openapi-typescript `src/lib/api/openapi.json` → `src/lib/api/schema.d.ts`; a no-op if the JSON is absent).
- **`.size-limit.json`:** the §10.1 budgets, ready to fill in. Initial JS for the search route ≤ 45 KB, CSS ≤ 20 KB, total first load ≤ 100 KB gzipped.
- **`.github/workflows/web.yml`:** Node 22, `npm ci`, `npm run check`, `npx vitest run`, `npm run build`, `npx size-limit`, run on PRs touching `web/**`.
- **`web/README.md`:** how to run and test it, plus the conventions above.

## Don't
- Build components, themes, fonts wiring, i18n messages or the API client (later slices).
- Edit anything outside `web/` and `.github/workflows/web.yml`.

## Done when
- `npm ci && npm run check && npx vitest run && npm run build && npx size-limit` pass locally. Add one trivial vitest test so the runner isn't empty.
- The PR description lists every dependency with its pinned version.
