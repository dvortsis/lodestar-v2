# C0: Contract documents for the UI
**Model:** Opus (docs only). **Branch:** `slice/C0`. **Spec:** architecture §10.2, §10.12, §10.14, §10.18, §20.9; skill files in `https://github.com/dvortsis/skills` (`ui-design-skills/skills/*/SKILL.md`, a public repo, so clone it read-only).

These three files are the contracts that let the theme compiler (W1), formatters (W8), primitives and screens be built in parallel by different sessions. Precision matters more than prose.

1. **`docs/design-tokens.md`:**
   - Every CSS custom property the UI may use, with its role and its source: the §10.18 derived tokens, the daisyUI 5 variables, `--data-1..6`, `--data-other`, `--brand-*`, the radii, the spacing ramp (§10.2), the type scale, the motion durations and easings, the control heights, density row heights and layout widths.
   - Name each token exactly as the theme compiler will emit it, and give Riverstone light and dark values where §10.18 gives them.
   - The rule: components use tokens only, with no hex and no arbitrary Tailwind values.
2. **`docs/metrics.md`:** the metric contracts from §10.12 and the Insights metrics from §10.9. For each metric:
   - its definition;
   - its unit and formatter (name, `Intl` options, IEC sizes);
   - how null, zero, estimated (≈) and sampled values display;
   - which time base it uses.

   Include the swarm fields from M4 (open PR #32 and what's merged on `main`). Read their exact names and nullability from the code and PRs, and note any field still pending.
3. **`docs/ui-glossary.md`:** the §10.14 glossary terms with one-line definitions and the exact UI label (en, plus zh where it's settled; mark the rest TBD).

Also add a short "UI field contract" table to `docs/metrics.md`: the JSON field names the API will expose for each metric, with nullability. B1 uses it for its DTOs.

**Done when:** the three docs exist, every token named in §10.2 and §10.18 appears exactly once, and there are no contradictions with architecture.md. If you find a contradiction, the architecture doc wins: add an item to the PR description.
