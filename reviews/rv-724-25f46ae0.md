**B2.**
- **How the hook works:**
  - `AFTER_PLACING` is a `thread_local! Cell<Option<fn(&Path)>>`.
  - It's declared, and used, only under `#[cfg(test)]`, so production builds and the integration-test builds of the lib don't contain it.
  - It runs right after the temp name is unlinked and before the dir-sync hook.
  - It's consumed with `Cell::take`, so it fires once.
- **Thread safety:** it's thread-local, and the test sets it on its own libtest thread right before a synchronous `append`. No other test can trip it, and nothing outlives the test's thread.
- **What the test checks:** `a_segment_swapped_out_after_placing_gets_the_appends` renames `<seq>.lsp` to `.moved` and writes "planted" at the name. It asserts:
  - the planted file is unchanged;
  - `.moved` is `s.bytes()` long, which is the header plus both frames;
  - `.moved` is longer than `HEADER_LEN + 2*FRAME_HEAD`.
- **Mutation** (drop the handle from `place_new`, then `OpenOptions::new().append(true).open(<seq>.lsp)` in `start_segment`): killed at `spool.rs:1555`. The integration suite still passes under it, as expected, so this new lib test is what kills it.

**I1.**
- **The sink:** a `OnceLock<Capture>` sink, installed through `lodestar_log::set_sink`. The only other `set_sink` in the crate's tests is `tests/requires.rs`, which is a different binary.
- **The test:** it builds segment 5001's damage (segment 1's file renamed to 5001's name, so its header names another number and `open()` drops it). It filters on `"segment=5001 "`, which no other test in the binary can produce, since their numbers stay small. It asserts exactly `[("pipeline.spool_damaged", ["segment","part"], "<message> segment=5001 part=header")]`.
- **Can't pass vacuously:** this is an equality with one element, so an empty capture fails.
- **No effect on other tests:**
  - With the sink installed, the binary's other events go into the Vec instead of the tracing fallback. No test reads either one.
  - `set_on(true)` on the pipeline catalogue changes only whether events are emitted. `SPOOL_DAMAGED` is on by default anyway.
  - The Mutex is held only for a push or a clone.
