- **The signal semantics, on real bash.** A TERM that arrives during a foreground command waits for that command to return. Then `exit 143` runs before the command's `|| { … }` branch, so `finish` is skipped and `cleanup` runs from the EXIT trap. A second TERM during `cleanup` is ignored, and `cleanup` runs to its end. So the flag-before-insert order is exactly what closes the window.
