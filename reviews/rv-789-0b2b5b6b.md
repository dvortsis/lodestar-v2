## Security review (no finding at medium or above)
- **Bounds:**
  - A message over 128 KiB is refused before it is read.
  - JSON depth is capped at 4.
  - The value cap is 64 + 512 × 17. A full event uses 8,715 of those 8,768 values.
  - Tags are capped at 512, and a tag holds 1–16 strings.
  - Strings decode only when asked for, and decoding never grows them.
  - Allocation is bounded by a small multiple of the message size.
  - Every iteration and dedupe loop has a constant bound (64 trackers, 32 ids, 64 tags).
- **Panics:**
  - Every slice uses `get` or `split_once`.
  - `InfoHash::from_str` decodes from bytes, so a 40-byte non-ASCII string can't split a character.
  - The bech32 shifts are bounded, and `cut` respects character boundaries.
- **Id integrity:**
  - id, pubkey and sig must be lower-case hex. That makes re-hexing the pubkey exact.
  - `created_at` and `kind` must be plain integers with no sign, fraction or exponent, and RFC 8259 grammar rules out leading zeros, so they serialise back exactly.
  - Each known field may appear only once, and the hash covers the decoded strings.
  - Escaping matches NIP-01's seven escapes. Other control characters fail closed as an id mismatch, which the decisions file records.
- **Log and display safety:**
  - Subscription ids containing hidden characters are refused.
  - Relay text (NOTICE, CLOSED, OK) has hidden characters removed, which covers ESC, CR and LF, and is cut to 256 bytes.
  - Names, files, tags and descriptions are filtered, and descriptions keep only `\n` and `\t`.
- **Key and trackers:**
  - The key comes only from `x`: 40 hex digits, not all zero, and two `x` tags that disagree drop the event.
  - A magnet in `content` is ignored.
  - Trackers get a scheme, length and whitespace check here. The SSRF check (`public_tracker_url`) is deferred to NOS-3 and documented on `Release::trackers`.
- **Content safety:** the adult flag is only a hint. Under plan Q-o4 it can only hide an item; ADH-0 decides what it does. Matching whole words means fewer attacker-driven hides, so no existing safety decision is weakened.
